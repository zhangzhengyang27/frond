# Leaf · 一句话定位

> **Leaf 是一款常驻 macOS 与 Windows 工作流的轻量桌面工具集，让创作、专注与娱乐在同一片"叶"上自然生长。**

## Slogan

> **Tools that breathe with your day.**

呼应"叶"的概念——工具像呼吸一样自然地伴随用户的一天，克制、不打断、可感而不可见。

## 调性

- 极简专业风（Raycast / Linear 范式）
- macOS 优先发布（Windows/Linux 源码可构建，产品化验证后再评估官方分发）
- 本地优先（无账号、无云同步的 1.0）
- 开源项目（GitHub 公开发布）
- 多合一工具集（与 CleanShot / Bob / Ticky 同一象限，不替代 Raycast / Notion / Figma）

## 已实现的核心能力（2026-09 更新）

> 以下能力已在代码中实际落地，定位文档据此同步更新。

- ✅ **启动器**：Alt+Space 胶囊唤起（1.2ms 热唤起）、命令注册表（**现状是两套并行**：`shared/commands.ts` 静态清单 + `shared/commandRegistry.ts` 仅 3 个 provider，收敛见 `RAYCAST_PARITY_PLAN_V5.md` P-7）、⌘K 命令面板、21 个第一方内联页
- ✅ **插件系统**：BrowserView 运行时 + 声明式 List 协议 + 偏好设置 + 网络代理 + 静态市场 v0 + 热重载开发模式
- ✅ **基础 AI**：OpenAI 兼容 Chat（用户自配 Key，baseUrl 可自定义）、流式响应、3 个预设命令（翻译/总结/改写）
- ✅ **截图库索引**：对既有截图目录做 on-device OCR 并可按图内文字/日期搜索 +「粘贴最近截图」（`ScreenshotIndexService`）；**截图捕捉本体已按 Decision-008 下线**（迁移独立项目，migration 028），本产品不含捕捉
- ✅ **屏幕录制**：录制 / 历史 / 回放 / 剪辑 / GIF 导出 / 摄像头画中画
- ✅ **番茄钟**：三模式 + 任务 + 多项目 + 统计 + 专注护盾（应用屏蔽）
- ✅ **系统集成**：系统命令包（6 条）、窗口管理（12 动作）、Quicklinks（参数化）、剪贴板历史（持久化/回车粘贴/置顶）、片段文本扩展（触发词/动态占位符/富文本）、文件搜索（mac mdfind）
- ✅ **快捷键体系**：主热键可配置、命令级全局热键、两段式直达

## 不做的事（1.0 范围内）

- ❌ **多语言**（1.0 仅中文）——**2026-09-20 复核维持不做，且是唯一维持项**（Decision-011 的明确例外）
- ❌ **移动端**（长期观望）
- ❌ **跑未改动的 Raycast 商店扩展**——不引入 Node worker 运行时；生态走自建远程索引分发（见 `RAYCAST_PARITY_PLAN_V5.md` P-3）
- ✅ **AI 平台化（2026-09-20 立项，Decision-011 推翻原「不做」）**：BYOM 多 provider（Ollama/OpenRouter/自定义兼容端点）、MCP client 最小面、Automations、Screen Awareness。原「AI 深化融入模块」四候选已全部落地（OCR 识字问 AI / 笔记摘要 / 番茄钟日报 / 剪贴板加工），本期在其之上继续
- ✅ **账号与双向云同步（2026-09-20 立项，Decision-011）**：本地优先重述为「本地优先 + **可选**端到端加密同步」——默认关闭、显式开启、密钥不出本机、不得要求先登录
- ✅ **自定义主题（已联动启动器）**：用户主题文件 `userData/themes/*.json` 已可用（`main/modules/userThemes.ts`），主题派生的 12 个 `--launcher-*` 表面/文本键会进胶囊窗（`launcherThemeVars()`）；**强调色与几何不联动**，那条 Decision-010 的拍板维持原样，边界见 Decision-012
- ✅ **Calendar 集成（2026-09-17 立项，完整对齐）**：原「不做」决策推翻。分期落地：系统日历只读（根搜索下一个会议）→ My Schedule → Create Event 写回 → 入会链接识别/自动入会。原本地假数据日历页由真实 EventKit 数据替代
