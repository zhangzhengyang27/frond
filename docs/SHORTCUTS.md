# Leaf · 全局快捷键

## 快捷键契约（门 / 家 三层）

| 层         | 快捷键      | 作用范围 | 职责                                                     |
| ---------- | ----------- | -------- | -------------------------------------------------------- |
| 门 · 全局  | Alt + Space | 全系统   | 唤起 / 隐藏启动台胶囊窗（搜索模块 / 插件命令 / 本机应用） |
| 截图 · 全局 | ⌥ ⇧ S      | 全系统   | 开始一次截图（`Alt+Shift+S`；2026-09-23 起可在启动台设置里改或关掉） |
| 门 · 窗口内 | ⌘ K        | 主窗口内 | 命令面板：窗口内跳转模块，与启动台同属「进入」层          |
| 家 · 直达  | ⌘ 2-4       | 主窗口内 | 直达对应模块页（录屏 / 番茄钟 / 启动器管理；⌘1 随截图模块下线空出） |

> 契约：门负责「进入」，家负责「停留」；⌘数字 只指向家中页面，不承担搜索。
> 模块与快捷键的绑定以 `src/shared/modules.ts` 的 `shortcut` 字段为准。
> 截图那一行是契约的另一档：它不指向任何页面，走的仍是全局热键。
> 2026-09-23 两处变更：① 默认从 ⌘⇧A 换成 ⌥⇧S（与微信等 IM 的默认截图键撞）；
> ② 从 `modules/screenshot.ts` 的硬编码 `globalShortcut` **接进 `launcher/hotkeys.ts` 的可配置热键系统**
> （存 `sys.hotkeys` 配置、启动台设置里可改可关）。接进来才有的两件事：
> 与主热键/命令热键同一套 `getHotkeyConflicts()` 冲突上报，以及 `unregisterAll` 后随恢复回调重挂。
> 它与 ⌘1 无关——2026-09-17 下线的是主窗口的「截图库」页面，截屏功能一直都在。
> 入口仍是两个：这条热键，与 `screenshot:startCapture`（渲染层按钮）；
> 命令表与胶囊里**没有**「开始截图」这条命令，所以它还不能像普通命令那样绑两段式直达。
> ⌘K 与启动台**已经**共享同一命令注册表、同一个命令源与搜索引擎（2026-09-20，P-7②：
> 静态清单并入 Registry，主窗面板改与胶囊共用 `useCommandSources()`）。
> 加权仍是同策略不同实例（两个渲染进程各持一份使用记录缓存）。

## 参数内联槽里的按键（P-1.6b）

回车选中一条**带 1-2 个文本/密码参数**的命令后，搜索框变成参数槽（命令名是一颗
不可编辑的 chip），此时键盘语义整套换掉：

| 键 | 作用 |
| --- | --- |
| `←` / `→` | 换格（夹在两端，不绕圈） |
| `Tab` / `⇧Tab` | 下一格 / 上一格，与 `←`/`→` 同一条规矩（夹在两端不绕圈）。`Tab` 在搜索框里仍是 Quick AI，两者不冲突：槽态下输入框没渲染 |
| `↵` | 执行（必填格空着则只标红那一格，不弹提示、不提交） |
| `⌫` | 第一格且已空时退出槽态回到搜索（正在删自己打的字时不退出） |
| `Esc` | 退出槽态回到搜索（不是关窗） |
| 数字 `1`-`0` | **打进格子里**，不是根列表的「第 N 条直达」——槽态下没有可见的列表可直达 |

输入法组合态（拼音还没上屏）里 `↵` / `Esc` / `←` / `→` 全部交回输入法：那时它们是选词键，
不是 Leaf 的动作键（与搜索框同一套守卫）。

≥3 个参数、或含 dropdown 的命令仍进表单页（`FormPage`）——内联条不是把所有表单塞进搜索框。
Quicklink 的槽位 = URL 里的占位符全集：`{query}` 与命名占位符（`{org}` 这类）都算一格
（`{encodedQuery}` 无人替换，不成槽）。

## 两段式直达（增量批次二）

主热键唤起胶囊后 **2 秒内按住主热键修饰键不放再按字母**，直达对应命令：

- 配置：启动器管理页「快捷键」区，每条命令的字母框（a-z，留空清除）
- 语义：要求主热键修饰键仍按住 → 与「唤起后直接打字搜索」无冲突
- 命令类型：模块（开沉浸窗）/ 系统命令 / Quicklinks / 内联页
- 例：主热键 Alt+Space、番茄钟配字母 `f` → `Alt+Space 按住 Alt 再按 F` 直达专注

## 片段文本扩展（M5.1）

任意应用中键入片段触发词（片段编辑器顶部设置，如 `;sig`）后按空格 / 回车，
自动回删触发词并展开为片段内容（剪贴板保存/还原，内容保留分隔符）。

- 开关与诊断：启动器管理页「片段文本扩展」区（macOS 需辅助功能授权）

## 实现位置

- 应用级全局（窗口显隐）→ `src/main/modules/globalShortcuts.ts`；录屏、番茄钟等模块快捷键通过 `addShortcutRestorer` 挂恢复回调，避免被 `unregisterAll` 清掉
- 番茄钟 → `src/main/modules/pomodoroShortcuts.ts`（默认值见 `PomodoroIntegrationService.DEFAULT_POMODORO_SHORTCUTS`）
- 屏幕录制 → `src/main/services/recording/GlobalShortcutService.ts`
- 应用内（应用在前台）→ `src/renderer/src/composables/useShortcut.ts`（基于 VueUse `useEventListener`）
- 命令面板 → 单独注册 ⌘K，并在 composable 中统一
